# HelpDesk Pro

A full-stack IT helpdesk ticketing app for my portfolio using example tickets. Users can view ticket metrics, browse and filter support requests, create new tickets, and manage status, priority, and notes.


## Tools Used

| Tool | Role in this project |
|------|----------------------|
| [React](https://react.dev/) | UI components and page structure |
| [Vite](https://vitejs.dev/) | Dev server and production build tooling |
| [TypeScript](https://www.typescriptlang.org/) | Type-safe JavaScript across the app |
| [Tailwind CSS](https://tailwindcss.com/) | Utility-first styling and responsive layout |
| [React Router](https://reactrouter.com/) | Client-side routing (`/`, `/tickets`, `/tickets/new`, `/tickets/:id`) |
| [Supabase](https://supabase.com/) | PostgreSQL database, REST API, and backend hosting |
| [@supabase/supabase-js](https://supabase.com/docs/reference/javascript/introduction) | Connects the frontend to Supabase from `src/lib/supabase.js` |
| [Lucide React](https://lucide.dev/) | Icons for navigation and dashboard |
| [Vercel](https://vercel.com/) | Frontend deployment and hosting |
